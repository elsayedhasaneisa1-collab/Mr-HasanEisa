# منصة امتحانات أستاذ حسن عيسى — Supabase
1) افتح Supabase > SQL Editor.
2) الصق schema.sql بالكامل واضغط Run.
3) ارفع index.html + style.css + app.js إلى GitHub Pages.
4) افتح الموقع ثم اضغط «الأستاذ» وأنشئ امتحانًا.
5) انسخ الرابط وأرسله للطلاب.
6) الطالب يفتح الرابط ويكتب اسمه ويبدأ.
7) وقت النهاية محفوظ في قاعدة البيانات ويُرجع للطالب كوقت انتهاء محدد، والتصحيح يتم داخل قاعدة البيانات ولا تُرسل الإجابات الصحيحة للطالب.

تنبيه: دوال إنشاء الامتحانات ونتائج الأستاذ في هذه النسخة مفتوحة للتجربة. قبل الاستخدام الحقيقي يجب إضافة حساب أستاذ وRLS وربط الامتحانات بمالكها.


## V4
- دخول الأستاذ بكلمة المرور الثابتة `25808`.
- زر «مسح بيانات الامتحانات» داخل لوحة الأستاذ.
- يطلب كلمة المرور مرة ثانية ثم تأكيد الحذف.
- الحذف يمسح الامتحانات والأسئلة والمحاولات والإجابات، **ولا يحذف قاعدة Supabase أو الجداول**.
- بعد تعديل `schema.sql` يجب تشغيل الجزء الجديد في Supabase SQL Editor مرة أخرى.
